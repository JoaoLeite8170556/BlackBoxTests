# Camry Found

Encontra Toyota Camry **reais** no AutoScout24 (Europa) e estima o custo de importação para Portugal (ISV, transporte, matrícula).

## Desenvolvimento

```bash
cd camry-found
npm install
npm run dev
```

Abre http://127.0.0.1:5173 — a API `/api/listings` obtém anúncios ao vivo do AutoScout24.

A calculadora de ISV é orientativa e não substitui o cálculo oficial da AT/IMT.
