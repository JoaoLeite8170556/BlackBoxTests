# Camry Found

Pesquisa **Mercedes-Benz, Audi, BMW e Volvo** no AutoScout24 (Europa) até **25 000 €** e **100 000 km**, com estimativa de custo de importação para Portugal.

## Desenvolvimento

```bash
cd camry-found
npm install
npm run dev
```

Abre http://127.0.0.1:5173 — a API `/api/listings` obtém anúncios ao vivo do AutoScout24.

A calculadora de ISV é orientativa e não substitui o cálculo oficial da AT/IMT.
